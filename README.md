# TERRA Campaign — BUILD-000

Base inicial para la PWA de visitas y promoción territorial.

## Abrir correctamente

No abras `index.html` con doble clic. Los módulos y el service worker requieren un servidor local.

En VS Code:

1. Abre la carpeta `terra-campaign`.
2. Instala la extensión **Live Server**.
3. Haz clic derecho en `index.html`.
4. Selecciona **Open with Live Server**.

## Archivos que se configurarán después

- `firebase-config.js`: datos del proyecto Firebase.
- `project-config.js`: API Key de Google Maps, campaña y ubicación inicial.
